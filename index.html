🍪 Oreo Help Panel

All Oreo's Commands

?helpMe

Displays the bot commands in the channel

?ping

Shows Oreo's latency

?userinfo

Sends user infos

?clear

Deleting messages from a channel

?clear number or ?clear all

?roast

Roasts an user (fun command)

?remind

Reminds you of something

?remind time(in seconds) message

?stats

Shows server stats

?autoclear start

Autoclears the channel each 2 mins

?autoclear stop

Stops autoclear

?setprefix

Changes Oreo's prefix for this server

Saved in a json file for each server

?music

Display all music commands
